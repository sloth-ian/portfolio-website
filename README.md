# portfolio-website

## basic overview
personal portfolio website to showcase my stuff

## the problem
The issue I am solving is a need to store my current and future projects somewhere, along with other things I want to showcase. 

## the solution
A personal website with modular capabilities so that I am able to add additional sections without breaking the main system. The focus of the website will be to showcase things. I believe this design would be considered a portfolio website.

## tech stack
Structure: HTML - Main website stuff (links and loading and stuff)
Styling: CSS - Cool styling stuff (transitions, the circle)
Behavior: JavaScript - background animation and stuff
Graphics: Canvas - animated background
Data: I don't store any consumer data for this (no logins or stuff)
Hosting: GitHub Pages or I might try using the school's provided webpage.
Tools: VS Code, Git, browser dev tools

Libraries: 
Audio: Howler.js - background music
Spacing: Tailwind CSS
Transitions: GSAP

## mvp
Basic website with working links, able to easily slot in additional links
